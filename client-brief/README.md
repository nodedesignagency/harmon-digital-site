# Client brief — Harmon Digital

Everything the client shares goes here, so it stays with the project instead of in chat history.

## What to collect

- [ ] Business name, tagline, short description
- [ ] Logo files (SVG preferred, plus PNG) → `client-brief/brand/`
- [ ] Brand colors (hex codes) and fonts
- [ ] Pages needed and their copy (one file per page, e.g. `home.md`, `about.md`, `services.md`)
- [ ] Services / offerings with descriptions
- [ ] Team members, testimonials, case studies / portfolio items
- [ ] Images and photos → `client-brief/images/`
- [ ] Contact details: email, phone, address, social links
- [ ] Domain name and where the site will be hosted
- [ ] Reference sites the client likes, and anything they want removed from the template

Text content can be pasted into `.md` files in this folder or shared in chat and saved here.
